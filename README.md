# AppGrupo5

Aplicación móvil nativa en **Android Studio** desarrollada por el Grupo 5 para el examen T2 de DESARROLLO DE APLICACIONES MOVILES I.  

---

## 📂 Estructura del Proyecto

- `MainActivity.kt` → Pantalla de Login (Pregunta 1).
- `HomeActivity.kt` → Pantalla principal con BottomNavigationView.
- `Pregunta1Fragment.kt` → Sobredimensión de carga.
- `Pregunta2Fragment.kt` → Demurrage de contenedores.
- `Pregunta3Fragment.kt` → Listado de países europeos con Glide.
- `Pregunta4Fragment.kt` → Consumo de API con Retrofit.
